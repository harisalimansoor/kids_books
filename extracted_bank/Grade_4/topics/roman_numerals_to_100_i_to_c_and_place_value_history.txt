=== Topic: Roman numerals to 100 (I to C) and place value history ===
Domain: Number and Place Value

--- Roman numerals to 100 (I to C) ---

Question 1: What number is represented by the Roman numeral LXXIII?
Answer: 73
Working: L = 50, XX = 20, III = 3. 50 + 20 + 3 = 73.

Question 2: Write the number 34 in Roman numerals.
Answer: XXXIV
Working: 30 = XXX, 4 = IV. 34 = XXXIV.

Question 3: What number is represented by the Roman numeral XLIX?
Answer: 49
Working: XL = 40 (50 - 10), IX = 9 (10 - 1). 40 + 9 = 49.

Question 4: Write the number 88 in Roman numerals.
Answer: LXXXVIII
Working: 80 = LXXX (50 + 30), 8 = VIII (5 + 3). 88 = LXXXVIII.

Question 5: What number is represented by the Roman numeral XCVI?
Answer: 96
Working: XC = 90 (100 - 10), VI = 6 (5 + 1). 90 + 6 = 96.

Question 6: Write the number 65 in Roman numerals.
Answer: LXV
Working: 60 = LX (50 + 10), 5 = V. 65 = LXV.

Question 7: Put these Roman numerals in order from smallest to largest: LVI, XLIV, LXII, XXXIX.
Answer: XXXIX, XLIV, LVI, LXII
Working: Convert each to Arabic numbers: XXXIX = 39, XLIV = 44, LVI = 56, LXII = 62. In order from smallest to largest: XXXIX, XLIV, LVI, LXII.

Question 8: Write <, > or = to make the statement true: XCIV [ ] LXXXVIII
Answer: >
Working: XCIV = 94 and LXXXVIII = 88. 94 is greater than 88, so XCIV > LXXXVIII.

Question 9: Calculate the sum of XXXV and XLIII. Give your answer as a Roman numeral.
Answer: LXXVIII
Working: XXXV = 35 and XLIII = 43. 35 + 43 = 78. 78 in Roman numerals is LXXVIII.

Question 10: Write the missing Roman numeral to complete the number sequence: XVII, XXIV, XXXI, ___, XLV.
Answer: XXXVIII
Working: XVII = 17, XXIV = 24, XXXI = 31, XLV = 45. The rule is adding 7 each time. 31 + 7 = 38. 38 in Roman numerals is XXXVIII.

--- Place value history ---

Question 11: Did the ancient Roman numeral system have a symbol to represent zero? Write yes or no.
Answer: no
Working: The Roman numeral system did not have a symbol for zero.

Question 12: Over time, numeral systems developed to use place value. In the number 408, what is the role of the digit 0?
Answer: placeholder
Working: In the place value system, 0 acts as a placeholder to show there are 0 tens.

Question 13: In our modern number system, how does the digit 0 change the value of the digit 7 in the number 70 compared to the single digit 7?
Answer: It gives 7 the value of 7 tens
Working: The digit 0 acts as a placeholder in the ones column, making the 7 represent 7 tens (70) instead of 7 ones.

Question 14: In the Roman numeral system, numbers are formed by adding or subtracting fixed letter values (such as X = 10, V = 5). In our modern numeral system, what determines the value of a digit within a number?
Answer: its place value
Working: In the modern base-10 system, the position or place value of a digit determines its value (e.g. hundreds, tens, ones).

Question 15: Why does the modern number system require a zero to write five hundred and six (506), whereas Roman numerals write DVI without a zero?
Answer: Zero is needed as a placeholder for the empty tens column
Working: Our place value system requires zero as a placeholder to hold the tens position, so the 5 remains in the hundreds column. Roman numerals do not use column place value.
