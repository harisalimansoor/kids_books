=== Topic: Properties of 0 and 1 (x 0, x 1, ÷ 1) ===
Domain: Multiplication and Division

--- Multiplying by 0 ---

Question 1: Calculate 487 × 0.
Answer: 0
Working: Any number multiplied by 0 equals 0. 487 × 0 = 0.

Question 2: Work out 0 × 62.
Answer: 0
Working: Zero multiplied by any number is 0. 0 × 62 = 0.

Question 3: Work out the value of 7 × 9 × 0.
Answer: 0
Working: 7 × 9 = 63. Then 63 × 0 = 0.

Question 4: There are 8 bowls on a table. Each bowl contains 0 grapes. How many grapes are there in total across all 8 bowls?
Answer: 0
Working: 8 groups of 0 grapes = 8 × 0 = 0 grapes.

Question 5: Find the missing number that makes the calculation correct:
315 × [ ] = 0
Answer: 0
Working: Any non-zero number multiplied by 0 gives 0. Therefore, the missing number is 0.

Question 6: Complete the statement using <, >, or =:
85 × 0 [ ] 0 × 142
Answer: =
Working: 85 × 0 = 0 and 0 × 142 = 0. Since 0 = 0, the correct symbol is =.

--- Multiplying by 1 ---

Question 7: Calculate 729 × 1.
Answer: 729
Working: Multiplying any number by 1 leaves the number unchanged. 729 × 1 = 729.

Question 8: Work out 1 × 384.
Answer: 384
Working: 1 × 384 = 384.

Question 9: Calculate 6 × 8 × 1.
Answer: 48
Working: 6 × 8 = 48. 48 × 1 = 48.

Question 10: A teacher buys 1 pack of 36 colouring pencils. How many colouring pencils does the teacher buy in total?
Answer: 36
Working: 1 × 36 = 36 pencils.

Question 11: Find the missing number to make the equation true:
[ ] × 1 = 592
Answer: 592
Working: Any number multiplied by 1 is itself. Therefore, the missing number is 592.

Question 12: Complete the statement using <, >, or =:
64 × 1 [ ] 64 + 0
Answer: =
Working: 64 × 1 = 64 and 64 + 0 = 64. Since 64 = 64, the correct symbol is =.

--- Dividing by 1 ---

Question 13: Calculate 86 ÷ 1.
Answer: 86
Working: Any number divided by 1 is the number itself. 86 ÷ 1 = 86.

Question 14: Work out 954 ÷ 1.
Answer: 954
Working: Dividing 954 into 1 group gives 954.

Question 15: Find the missing number:
418 ÷ [ ] = 418
Answer: 1
Working: A number divided by 1 gives the same number. 418 ÷ 1 = 418, so the missing number is 1.

Question 16: A baker has 52 cupcakes. She puts all the cupcakes into 1 large display box. How many cupcakes are in the box?
Answer: 52
Working: 52 ÷ 1 = 52 cupcakes.

Question 17: Work out the value of (340 ÷ 1) - (340 × 0).
Answer: 340
Working: 340 ÷ 1 = 340 and 340 × 0 = 0. 340 - 0 = 340.

Question 18: Complete the statement using <, >, or =:
275 ÷ 1 [ ] 275 × 1
Answer: =
Working: 275 ÷ 1 = 275 and 275 × 1 = 275. Both sides are equal to 275, so the correct symbol is =.
