--- Enumerating combinations of two variables satisfying constraints ---

Question 1: The letters a and b represent positive whole numbers. Given that a + b = 6, list all the possible pairs of values for (a, b).
Answer: (1, 5), (2, 4), (3, 3), (4, 2), (5, 1)
Working: Positive whole numbers start at 1.
If a = 1, b = 5.
If a = 2, b = 4.
If a = 3, b = 3.
If a = 4, b = 2.
If a = 5, b = 1.
The possible pairs (a, b) are (1, 5), (2, 4), (3, 3), (4, 2), (5, 1).

Question 2: The letters x and y represent whole numbers. If x + 2y = 14 and x = 4, what is the value of y?
Answer: 5
Working: Substitute x = 4 into the equation:
4 + 2y = 14
2y = 14 - 4
2y = 10
y = 5

Question 3: The letters m and n represent positive whole numbers. Given that 3m + n = 15, list all possible pairs of values for (m, n).
Answer: (1, 12), (2, 9), (3, 6), (4, 3)
Working: Since m and n are positive whole numbers, m must be at least 1:
If m = 1: 3(1) + n = 15 => n = 12
If m = 2: 3(2) + n = 15 => n = 9
If m = 3: 3(3) + n = 15 => n = 6
If m = 4: 3(4) + n = 15 => n = 3
If m = 5: 3(5) + n = 15 => n = 0 (not positive).
The pairs are (1, 12), (2, 9), (3, 6), (4, 3).

Question 4: A school hall has large tables that seat 6 pupils and small tables that seat 4 pupils. Exactly 32 pupils need to be seated, with no empty seats. The hall must use at least one large table and at least one small table. List all possible pairs of (large tables, small tables).
Answer: (2, 5) and (4, 2)
Working: Let L be the number of large tables and S be the number of small tables: 6L + 4S = 32.
Test possible values for L:
If L = 1: 6(1) + 4S = 32 => 4S = 26 (26 is not divisible by 4).
If L = 2: 6(2) + 4S = 32 => 12 + 4S = 32 => 4S = 20 => S = 5.
If L = 3: 6(3) + 4S = 32 => 18 + 4S = 32 => 4S = 14 (not divisible by 4).
If L = 4: 6(4) + 4S = 32 => 24 + 4S = 32 => 4S = 8 => S = 2.
If L = 5: 6(5) + 4S = 32 => 30 + 4S = 32 => 4S = 2 (not divisible by 4).
The possible pairs (large tables, small tables) are (2, 5) and (4, 2).

Question 5: The letters x and y represent positive whole numbers. Given the equation 2x + 3y = 24, how many different pairs of values for x and y satisfy this equation?
Answer: 3
Working: 2x + 3y = 24, where x and y are positive integers (x >= 1, y >= 1).
Rearrange: 2x = 24 - 3y.
Since 2x and 24 are even, 3y must also be even, so y must be an even number.
Test positive even values for y:
If y = 2: 2x = 24 - 6 = 18 => x = 9 (valid pair: (9, 2))
If y = 4: 2x = 24 - 12 = 12 => x = 6 (valid pair: (6, 4))
If y = 6: 2x = 24 - 18 = 6 => x = 3 (valid pair: (3, 6))
If y = 8: 2x = 24 - 24 = 0 => x = 0 (not positive).
There are 3 pairs.

Question 6: In a playground shed, there are only bicycles (2 wheels each) and tricycles (3 wheels each). Altogether there are 23 wheels. There is at least 1 bicycle and at least 1 tricycle. Write down all the possible combinations as (bicycles, tricycles).
Answer: (10, 1), (7, 3), (4, 5), (1, 7)
Working: Let b be the number of bicycles and t be the number of tricycles: 2b + 3t = 23.
2b is always even, so 3t must be odd (since even + odd = 23).
Therefore, t must be an odd positive whole number:
If t = 1: 2b + 3 = 23 => 2b = 20 => b = 10
If t = 3: 2b + 9 = 23 => 2b = 14 => b = 7
If t = 5: 2b + 15 = 23 => 2b = 8 => b = 4
If t = 7: 2b + 21 = 23 => 2b = 2 => b = 1
If t = 9: 2b + 27 = 23 (not possible).
The combinations (bicycles, tricycles) are (10, 1), (7, 3), (4, 5), (1, 7).

Question 7: A baker sells boxes of 6 cupcakes and boxes of 10 cupcakes. A customer buys exactly 52 cupcakes in total, purchasing more boxes of 10 than boxes of 6. How many boxes of cupcakes does the customer buy altogether?
Answer: 6
Working: Let x be the number of 6-cupcake boxes and y be the number of 10-cupcake boxes:
6x + 10y = 52
Test values for y:
If y = 1: 6x + 10 = 52 => 6x = 42 => x = 7 (here y is not greater than x)
If y = 2: 6x + 20 = 52 => 6x = 32 (32 is not divisible by 6)
If y = 3: 6x + 30 = 52 => 6x = 22 (not divisible by 6)
If y = 4: 6x + 40 = 52 => 6x = 12 => x = 2 (here y = 4 > x = 2, so this satisfies the condition)
If y = 5: 6x + 50 = 52 => 6x = 2 (not divisible by 6)
Total boxes = x + y = 2 + 4 = 6 boxes.

Question 8: The letters a and b are positive whole numbers such that a × b = 36 and a < b. List all the possible values of the sum a + b.
Answer: 13, 15, 20, 37
Working: Find factor pairs of 36 where a < b:
Pair 1: a = 1, b = 36 => a + b = 1 + 36 = 37
Pair 2: a = 2, b = 18 => a + b = 2 + 18 = 20
Pair 3: a = 3, b = 12 => a + b = 3 + 12 = 15
Pair 4: a = 4, b = 9 => a + b = 4 + 9 = 13
(Note: 6 × 6 = 36 is excluded because a must be strictly less than b).
The possible values of the sum are 13, 15, 20, 37.

Question 9: Amir has only 20p coins and 50p coins. The total value of his coins is £3.60. He has at least one of each coin. What is the greatest possible number of coins Amir could have in total?
Answer: 15
Working: Let x be the number of 20p coins and y be the number of 50p coins.
£3.60 = 360p.
20x + 50y = 360, dividing by 10 gives 2x + 5y = 36.
To maximise the total number of coins (x + y), we need to maximise the number of 20p coins (x) and minimise the number of 50p coins (y).
Since 2x and 36 are even, 5y must be even, meaning y must be an even whole number.
The smallest positive even whole number is y = 2:
2x + 5(2) = 36
2x + 10 = 36
2x = 26
x = 13
Total number of coins = 13 + 2 = 15.
