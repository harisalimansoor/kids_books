=== Topic: Decimal and fraction equivalences for tenths, hundredths, and thousandths ===
Domain: Fractions, Decimals and Percentages

--- Decimal and fraction equivalences for tenths ---

Question 1: Write 7/10 as a decimal.
Answer: 0.7
Working: 7 tenths is written as 0.7.

Question 2: Write 0.3 as a fraction.
Answer: 3/10
Working: 0.3 represents 3 tenths, which is 3/10.

Question 3: Write the mixed number 2 9/10 as a decimal.
Answer: 2.9
Working: 2 wholes and 9 tenths is equal to 2 + 0.9 = 2.9.

Question 4: Write 4.1 as a mixed number.
Answer: 4 1/10
Working: 4.1 has 4 whole ones and 1 tenth, which is 4 1/10.

Question 5: A ribbon is 16/10 metres long. Write this length as a decimal in metres.
Answer: 1.6
Working: 16/10 = 1 6/10 = 1.6 metres.

Question 6: Complete the statement to make it correct: 5/10 + 0.3 = ?
Answer: 0.8
Working: 5/10 = 0.5. 0.5 + 0.3 = 0.8 (or 8/10).

--- Decimal and fraction equivalences for hundredths ---

Question 7: Write 43/100 as a decimal.
Answer: 0.43
Working: 43 hundredths is written as 0.43.

Question 8: Write 7/100 as a decimal.
Answer: 0.07
Working: 7 hundredths has 0 tenths and 7 hundredths, so it is written as 0.07.

Question 9: Write 0.71 as a fraction with a denominator of 100.
Answer: 71/100
Working: 0.71 represents 71 hundredths, which is 71/100.

Question 10: Write the mixed number 3 29/100 as a decimal.
Answer: 3.29
Working: 3 wholes and 29 hundredths is 3 + 0.29 = 3.29.

Question 11: Write 0.09 as a fraction.
Answer: 9/100
Working: 0.09 is 9 hundredths, which is written as 9/100.

Question 12: A plank of wood has a length of 2.05 metres. Write 2.05 as a mixed number.
Answer: 2 5/100
Working: 2.05 has 2 wholes and 5 hundredths, which is 2 5/100 (or 2 1/20).

Question 13: What decimal is equivalent to 6 tenths and 4 hundredths?
Answer: 0.64
Working: 6 tenths = 0.6 and 4 hundredths = 0.04. 0.6 + 0.04 = 0.64.

--- Decimal and fraction equivalences for thousandths ---

Question 14: Write 341/1000 as a decimal.
Answer: 0.341
Working: 341 thousandths is written as 0.341.

Question 15: Write 0.127 as a fraction with a denominator of 1000.
Answer: 127/1000
Working: 0.127 represents 127 thousandths, which is 127/1000.

Question 16: Write 59/1000 as a decimal.
Answer: 0.059
Working: 59 thousandths has 0 tenths, 5 hundredths, and 9 thousandths, which is 0.059.

Question 17: Write 3/1000 as a decimal.
Answer: 0.003
Working: 3 thousandths has 0 tenths, 0 hundredths, and 3 thousandths, which is 0.003.

Question 18: Write 0.017 as a fraction.
Answer: 17/1000
Working: 0.017 is 17 thousandths, which is written as 17/1000.

Question 19: Write the mixed number 5 83/1000 as a decimal.
Answer: 5.083
Working: 5 wholes and 83 thousandths is 5 + 0.083 = 5.083.

Question 20: A parcel weighs 1.006 kg. Write 1.006 as a mixed number.
Answer: 1 6/1000
Working: 1.006 has 1 whole and 6 thousandths, which is written as 1 6/1000.

Question 21: What decimal is equivalent to 4 tenths, 0 hundredths, and 7 thousandths?
Answer: 0.407
Working: 4 tenths = 0.4, 0 hundredths = 0.00, 7 thousandths = 0.007. Total = 0.407.
