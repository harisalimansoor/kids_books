# `utils.py`

<!-- ## What This Script Does -->
This script contains small, helpful, and reusable utility functions that can be used throughout the app. Right now, its main jobs are:
- Cleaning up the raw text generated by the AI (removing strange bullet points, correcting spacings, taking out extra numbering).
- Converting text into a safe format for generating PDFs so there are no encoding errors.
- Sanitizing file names (taking "Student Name" and creating a clean `math_workbook_for_Student_Name.pdf`).

## How to Run It
This script is **not meant to be run directly**. It's just a toolkit file that other scripts (like `app.py` or `pdf_generator.py`) will import functions from whenever needed.

## Required Input / Output
- **Inputs**: It accepts messy strings or variables (like raw AI text output, or a student's typed name).
- **Outputs**: It returns clean, safe-to-use strings and lists that are properly formatted for saving into the final PDF.
