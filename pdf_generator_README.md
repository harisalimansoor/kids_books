# `pdf_generator.py` — PDF Workbook Generation

## Purpose
Generates an A4 PDF workbook with personalised math questions and optional AI-generated images using the `fpdf` library.

## Public API

### `generate_pdf(student_name, grade, topic_header_text, questions, image_paths=None) -> bytes`
- **`student_name`**: Student's name for the workbook title
- **`grade`**: Grade level string (e.g. "Grade 1")
- **`topic_header_text`**: Topics covered (e.g. "All topics" or "Addition, Subtraction")
- **`questions`**: List of personalised question strings
- **`image_paths`**: Optional list of image file paths (same length as questions). `None` entries skip images for that question
- **Returns**: PDF bytes encoded as Latin-1

## Layout
- **Header**: "Personalized Math Workbook: {name} ({grade})" — dark blue, size 18, bold, centered
- **Subheader**: "Focus: {topics}" — soft grey, italic, size 12, centered
- **Divider**: Grey horizontal line
- **Each question**:
  - Image block (95mm wide, centered at x=57.5) — scaled proportionally, auto page break if insufficient space
  - Question number + text — dark charcoal, size 12
  - Subtle grey divider line
- **Footer**: "Generated by the Personalized Math App" — light grey, italic, size 10

## Image Handling
- Images are resized to 95mm width maintaining aspect ratio
- Auto page break when there's insufficient room for image + text + divider
- If an image file can't be opened, a warning is shown via `st.warning()` and the question continues without image
- `None` entries in `image_paths` are handled gracefully

### `cleanup_temp_images(image_paths: list)`
Removes temporary image files from disk. Silently ignores missing files and permission errors.

## Text Safety
All text passed to `fpdf` is encoded through `safe_text()` from `utils.py` to strip non-Latin-1 characters, preventing PDF encoding errors.

## Dependencies
- `fpdf` (FPDF class)
- `PIL` (Image — for sizing calculations)
- `os`, `streamlit`
- `utils` — `safe_text`
