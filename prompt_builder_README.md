# `prompt_builder.py` — Legacy Prompt Builder

## Purpose
Provides prompt construction utilities originally used for LLM-based question generation. Currently, `build_family_context()` is the only function still actively called in the pipeline; the rest are legacy.

## Active Functions

### `build_family_context(mother_name, father_name, grandmother_name, grandfather_name, siblings) -> str`
Builds a human-readable family context string from provided names.
- Formats as `"mother Alice, father Bob, grandmother Carol, grandfather Dave, siblings Eve"`
- Returns `"no specific family mentioned"` if all fields are empty
- **Called by**: `app.py` during the generation flow (for potential use, though not currently passed to the AI renderer)

## Legacy Functions (not actively called)

### `get_pronouns(gender: str) -> tuple[str, str]`
Returns `(pronoun, possessive)` based on gender:
- "Boy" → `("he", "his")`
- "Girl" → `("she", "her")`
- "Other" → `("they", "their")`

### `build_prompt(student_name, gender, grade, topic_context, extracted_text, num_questions, family_context, hobbies_context) -> str`
Builds a complete `ChatPromptTemplate` for LLM-based question generation using `langchain_core`.
- Includes student name, pronouns, family members, hobbies, and sample questions
- **Not used** in current pipeline — questions are selected from the pre-existing templated bank rather than generated by an LLM

## Dependencies
- `langchain_core` (ChatPromptTemplate)
